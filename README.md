# benhigham/.github

Default [community health files][chf] for all repositories under my account.

[chf]: https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file

GitHub uses these as defaults for any repository that doesn't have its own version:

- `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, `GOVERNANCE.md`
- `.github/FUNDING.yml`
